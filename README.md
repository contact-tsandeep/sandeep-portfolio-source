# Sandeep — Digital Builder

A premium 3D developer/founder landing page with an interactive hero, floating 3D objects, smooth scrolling, animated tech elements, and interactive project/company sections.

## Stack

- React 19
- Vite 8
- TypeScript 7
- Tailwind CSS 3
- @react-three/fiber + @react-three/drei
- Three.js
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/`.

## Deploy

GitHub Actions deploys automatically on push to `main` (`.github/workflows/deploy.yml`).
Repository Settings → Pages → Source: **GitHub Actions**.
